来源：用户提供的 `D:/下载/` 下 15 个 GLB，2026-11-08 复制。原文件未覆盖或重导出；Godot 使用自动 LOD、阴影网格和原有贴图。

场景为 `res://scenes/table_view.tscn`，所有实例均可在编辑器中调整。`Table` 是圆桌；`Props` 是托盘、五种骰子和钥匙；`Chips` 是三色筹码堆与散筹；`Characters` 是四个冒险者实例。其余房间和灯具沿用布局模型。

- 圆桌直径约 2.24 m、外沿高度约 0.84 m；为匹配原有赌桌占地，桌子使用横向 2.24、纵向约 1.121 的缩放。内侧桌面约 0.809 m，托盘内底约 0.880 m。
- 角色统一到约 1.76 m，原模型朝向 +X。编号 `(1)` 与 `(2)` 完全相同；四份文件是同一角色的静态／骨架版本，不能当作四个不同人物。原文件未附动画，且源蒙皮权重异常；`assets/characters/motion/adventurer_motion.glb` 已重新绑定并制作 idle、walk、seated 动作，桌边两人使用该副本坐到椅子上，后方两人保留原始站姿。主角的四方向步行帧也来自该动作副本。
- 钥匙旋转 90° 平放，三种筹码各自堆叠。骰子尚未绑定点数或规则；原贴图与骰面不能作为正式赌局逻辑的依据。
- “glass dice”和“transparent dice”源 GLB 的材质均只有颜色贴图和常规粗糙度，未提供真实透射；当前沿用文件外观。
- 原模型多为百万面级，保留用于当前布置预览。自动 LOD 已开启；后续正式动画与交互接入前仍需按目标平台评估网格和贴图预算。
