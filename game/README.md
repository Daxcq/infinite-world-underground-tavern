# 地下酒馆 · 对话与三幕试玩

运行环境：Godot **4.7.2**，GDScript，Compatibility 渲染器。针对 Windows 键盘与鼠标；无额外插件或 .NET 编译依赖。

**v2 对话与状态机已接入 F5 主流程。** 三人主线可从教学玩到三类碎片合钥，并结算责任与眼手心；独立试玩数值、操作和仍停止的未定分支见 [对话接入说明](对话接入说明.md)。

## 背景音乐

游戏启动后自动循环播放《锈蚀心跳·地下赌局》，覆盖标题、酒馆探索、第一人称赌桌与地下赌局。音乐默认音量为 40%；进入游戏后按 Esc，在暂停菜单调整“音乐音量”，0% 为静音。暂停时音乐继续播放；场景切换、重新开始均保留播放进度和本次运行的音量，退出游戏后音量恢复默认值。

音乐使用现有试听曲的 OGG 副本，保留原曲约 2 分 07 秒的编排与首尾淡入淡出，每次播完从头循环。原始 WAV、MP3 和制作资料保存在根目录 `音乐/`，未覆盖。音源与转换说明见 [音频素材说明](assets/audio/README.md)。

## 原酒馆满座与 NPC

F5 / 根目录 `开始试玩.cmd` 已沿用原来的暖光俯视酒馆底图，四桌分别安排 3、4、4、4 位酒客，吧台安排 4 位客人，另有酒保、绿衣同伴和可操控主角；上方左桌的右座留给玩家。底图与用户确认图片的 RGB 像素完全一致。

探索人物改为独立 3D 世界实时渲染：身体使用网格和骨骼，桌椅及吧台具有对应的深度遮挡，酒杯挂在手骨骼上；2D 移动控制器继续负责路线、碰撞和交互，主角的外套及肩包已计入避让距离。当前人物仍为简化造型与服饰变体，尚未逐一精修成全部像素设定稿。实机整图与验收见 [原酒馆人物布置](../美术资产/原酒馆_人物布置_v1/README.md)。

## 地下深层赌桌

地下深层赌桌可双击根目录 `进入地下赌局.cmd` 直接游玩，跳过教学，骰子仍正常随机。玩家＋任选一名桌边 NPC＋酒保三人入局；查看人物卡时用“桌边人物”下拉框切换，镜头转向对应人物，确认后该人物入席。酒保负责宣注、掷骰与结算。头顶聚光照亮赌桌，外围人群渐隐于黑暗，环顾时可抬头与回头查看。

七种不同 NPC 已接入选择和三幕流程，新角色暂共用现有基础规则，多数仍为源模型站姿；桌面道具的外观骰面不代表实际点数，结算以交互 UI 为准。

## 像素长廊空间小样

双击根目录 [体验像素长廊小样.cmd](../体验像素长廊小样.cmd)，或在 Godot 打开 `scenes/corridor_3d.tscn` 按 F6。WASD 移动、Shift 快步、Tab 查看桌边近景；走到空椅右侧按 E 落座，拖动鼠标左键或 A / D 环顾，E / Esc 起身。

这是独立的一桌样片：画面采用俯视像素观感，身体、桌椅、酒杯均为实体 3D，酒杯通过手骨骼挂点跟随举杯动作。人物是按像素稿配色制作的简化模型，并非全部角色的最终美术。原 F5 主流程保留；本入口尚未接入教学、正式赌局与剧情。模型源文件、预览与验收见 [像素长廊小样说明](../美术资产/像素长廊小样_v1/README.md)。

## 开始游玩

在仓库根目录双击 `开始试玩.cmd`，它使用本机已验证的 Godot 安装路径。也可以用 Godot 导入本目录的 `project.godot`，按 **F5** 启动主场景。换电脑后使用后者，或通过根目录 `开始试玩.ps1 -GodotPath <Godot程序路径>` 启动。

操作：WASD / 方向键移动，Shift 快步，E 与附近目标交互。对话逐字出现时按 E / Enter 显示整句；继续阅读可按 E，选项可用方向键、Tab、Enter 或鼠标操作。普通酒馆 Esc 可收起对白，赌桌 Esc 暂停；F11 切换全屏。金额与骰子在专门确认页提交，认负也需再次确认。

游玩路线：**吧台普通免费酒 → 左侧圆桌落座 → 两轮教学 → 地下转场 → 角色卡 → 合注、共渡、清桌**。点“环顾桌面”后可用鼠标或 A / D 观察，E 回到当前抉择。教学期间可起身，地下阶段不能起身返回地上。正式局可从当前人物名单选同伴，按真实掷骰和策略结算；未定分支会明确停止。

直接看本次 3D 资产布置：双击根目录 `查看3D资产场景.cmd`，或打开 `scenes/table_view.tscn` 按 **F6**。独立预览可用 A / D 环顾，按住鼠标左键拖动调整视角；关闭窗口退出。场景中的 `Table`、`Props`、`Chips`、`Characters` 和 `Room` 可直接在编辑器中调整。

## 本轮实现

- 标准八向移动、斜向归一化、快速制动、墙壁／家具／NPC 碰撞和受限的平滑跟随镜头。
- 主角与酒客使用实时 3D 网格和骨骼，保持像素 RPG 人物观感；移动、停步与对话同步切换动作，脚底投影与碰撞位置保持对应。原四方向图集保留为旧素材。
- 按实际位置绘制的家具遮挡，人物以脚部作为碰撞和排序基准。
- 只突出最近且没有障碍挡住的交互目标，不跨桌或穿墙触发。
- 酒保和同伴对话、雨窗与出口查看、渐进目标引导。取消对话不会误记完成。
- 落座确认、黑场切换、固定座位的第一人称 3D 观察和安全返回，保留本次探索状态。
- 键鼠共用的界面焦点、暂停／继续、重新开始确认、失焦自动暂停、全屏和视角灵敏度。

## 当前制作边界

当前已接入 v2 对话、教学、地下转场、三幕结算、器官操作限制与胜败结局，属于有明确未定分支的可玩版本；尚未完成所有结局线路、正式动画／音效、存档或完整 8—12 分钟体验验收。详见 [实际接入范围](对话接入说明.md)。

主角已接入真实手脚迈步的四方向动画；2D NPC 仍使用现有静态图集。第一人称赌桌沿用首批圆桌、金属托盘、五种骰子、三种筹码和钥匙，桌边两人使用修复蒙皮后的坐姿副本，后方两人保持站姿；补齐了三把座椅。原始 15 个模型保存在 `assets/models/`，未覆盖。墙体、窗户和灯具仍为布局模型，逻辑层赌具操作由 UI 托盘承载，3D 取放与骰面动画待制作；“玻璃／透明”骰子的源材质没有透射参数，当前沿用原贴图。正式模型与动画生产需求见 [首批建模包](../美术资产/3D首批建模包_v3/README.md)。

对白来自 v2 节点数据；仅责任者受罚，玩家受罚才推进眼→手→心。界面支持出资、骰子逐枚选择、单手放回托盘、窥牌眼、哑骰与安全确认。地下离座限制已生效。

## 工程结构

`scenes/main.tscn` 组合 `tavern.tscn`、`table_view.tscn` 和 `game_ui.tscn`；`actor.tscn` 是人物预制场景。脚本按控制器、场景、交互、UI 和流程分开。`scenes/music.tscn` 是跨场景常驻的音乐播放器，经 `default_bus_layout.tres` 的 Music 总线输出；没有引入第三方对话插件。

场景底图来自 `美术资产/首批_v1/01_场景背景/现实酒馆_无人物底图.png`。同伴来自首批图集，酒保来自 `美术资产/角色统一版_v2/02_RPG六姿态/`。主角步行图集为 `assets/characters/motion/player_walk.png`，动作副本为同目录 `adventurer_motion.glb`；可编辑骨架与动作保存在 `美术资产/角色动作_v1/冒险者_行走与坐姿.blend`。没有更换角色设计；原始素材未覆盖。

动作复现：用 Blender 5.2 后台运行根目录 `tools/build_character_motion.py`，再用 Python + Pillow 运行 `tools/pack_player_walk.py`。输出包含 idle、walk、seated 三个骨架动作，以及四方向图集（每行首帧为站姿，其后 12 帧为步行）。当前坐姿是稳定姿态，落座／起身仍沿用原黑场转场。

```powershell

& 'D:\Godot_v4.7.2-stable_mono_win64\Godot_v4.7.2-stable_mono_win64_console.exe' --headless --path . --script res://tests/playtest.gd
```

测试包含真实物理输入、方向键映射、斜向速度、碰撞、可通行路线、交互触达、取消与完成对话、键盘操作、暂停、反复落座和重新开始。失败返回非零进程退出码，并有超时保护。
