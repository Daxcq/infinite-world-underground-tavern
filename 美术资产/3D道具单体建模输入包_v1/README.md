## 上传与复用

- 每张图片建立一个独立图生 3D 任务；这些图片是不同资产或材质状态，不是同一模型的多视图。`00_道具总览_仅供查看.jpg` 只供浏览，不要上传为一个模型。
- 建议先验证 01 普通骰子、02 暗红筹码、05 托盘和 11 完整钥匙。导出带贴图的 GLB；这些道具不要求人形骨骼。
- 三色筹码复用一个网格和三套材质；一枚骰子可复制为多枚，不必为 1—6 点分别生成六个模型。必须核对模型六面点数及相对面点数和为 7。
- 三种器官骰共用透明骰壳，替换内部眼／手／心符号。图生 3D 可能把折射、符号和反光烘焙成表面图像，后续应把玻璃壳和符号拆为独立网格／材质。
- 钥匙 11 是完整基准，12—14 是碎片造型参考。建议生成完整钥匙后精确切分三段，再使用相同变换拼合；单独生成的三段不能假定尺寸和接口自动吻合。
- 酒杯的杯体、酒液，窥牌眼的镜框、镜片，面具的瓷壳、眼镜，应保留独立材质；面具已有模型时可从荷官模型拆出，不必重复生成。
- 灰底和局部阴影只用于参考构图，不作为模型地板或底座。面具按新版白瓷悲剧表情，不沿用旧版无表情椭圆面具。
