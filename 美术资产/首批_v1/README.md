## 使用说明与边界

- 本批交付的是静态背景、透明图集、姿态素材和剧情插图。角色姿态不是已对齐、可直接循环播放的动画帧。
- 图集尚未裁成单件，也未统一原点、碰撞区与显示尺寸。部分图集采用自适应排版，不应按文件名中的格数直接等分裁切；请按实际轮廓取区域。
- 主角在赌桌左下8点方向、同伴在右下4点方向、荷官在上方12点方向。入引擎时校准坐姿朝向、椅背和桌沿遮挡，让三席保持120度分布。
- 酒客为上身叠加素材，可放在已有圆桌后；荷官半身稿用于吧台或桌边，地图人物优先采用全身稿。
- 家具图集与已摆好家具的背景是两种使用方式；不要未经移除背景旧家具便重叠放置同一物件。
- 背景保留了烘焙氛围光，不是PSD式逐像素配准分层工程。灯光与特效透明素材可另作叠加，仍需引擎调光。
- 权贵素材保留衣料细节以便复用；在虚幻场景中应统一压暗，只露侧脸、头饰和金线的微弱侧光。
- 骰面1—6、命筹与钥匙进度图标已在生成预览中逐项核对。文件校验覆盖PNG解码、尺寸、透明通道和提示词文件存在性；未做Godot运行验收。
- 未修改玩法文档和现有概念图。连续动画、切帧、像素边缘细修及Godot场景装配属于下一制作步骤。
