## 固定的角色身份和造型

- **酒保：** 黑发、真人窄长脸、圆形金丝眼镜、黑领结、深色提花长礼服、暗红口袋巾。
- **新版荷官：** 黑发、圆形金丝眼镜、白色悲剧面具、黑领结、深色提花长礼服、暗红口袋巾。
- **阿努比斯：** 直立长耳、象牙色犬首、青绿眼、黑色头巾、黑领带、黑金暗红长礼服、深色爪手。

酒保和荷官分别保留真人面孔与面具特征，不根据相似西装自动合并角色身份。源文件名“面具立绘-微笑版”与画面表情不一致，本批按实际可见的皱眉、下弯张口戏剧面具造型转换。基础资产清理了血迹、碎杯、悬浮赌具和烟雾；这些不是模型身体的一部分。

新立绘只展示部分身体，下半身由同一套礼服风格补全；背面和最终模型结构仍须在 Tripo 输出后验收。

### 酒保

一个完整成年男性酒保，正面全身 A 姿势。严格保留参考图的黑色后梳头发、窄长真人面孔、圆形金丝眼镜、黑领结、米白衬衫、炭黑提花礼服与马甲、暗纹长裤和黑皮鞋。双手空置、手指分开，双腿分开，背面和脚底结构完整。无面具，无酒杯、场景、底座或额外人物。手绘写实游戏材质。

建议导出文件名：`bartender-v2.glb`。

### 新版荷官

一个完整成年男性荷官，正面全身 A 姿势。保留黑色后梳头发、戴在白瓷戏剧面具外的圆形金丝眼镜、空眼孔、皱眉和向下张开的嘴部雕刻，面具为干净无血迹的基础状态。保留黑领结、米白衬衫、炭黑提花长礼服与马甲、暗纹长裤和黑皮鞋。双手空置、手指和双腿分开，补齐背面与鞋底。不要变成真人脸、旧版棕发马甲荷官或无表情椭圆面具。无酒杯、场景与底座。

建议导出文件名：`dealer-v2.glb`。

### 阿努比斯

一个完整阿努比斯人形赌徒，正面全身 A 姿势。保留直立长耳、细长象牙色犬首、青绿眼、连在头后的黑色金边头巾、黑色长领带、米白衬衫、黑金提花长礼服、暗红翻领与内衬、少量贴附金色埃及饰件。两条人形长腿、黑色暗纹长裤和皮鞋，双手为分离清楚的深色五指爪手。衣摆开口以便后续屈膝坐姿。无骰子、天平、烟雾、魔法、漂浮锁链、场景或底座。全耳、手、脚及背面完整。

建议导出文件名：`anubis-v2.glb`。
