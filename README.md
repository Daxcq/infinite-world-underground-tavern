本版替代上一轮讨论中的双人三骰比点、每局一次重掷、四枚命筹及第四次失败淘汰方案。后续设计、制作与路演以当前主方案为准：

- 默认主角、NPC同伴、荷官三人同桌；筹码足够时可选择独狼二人局。
- 三幕依次为合注局、共渡局、清桌局，贯穿出资、合作与对决。
- 合注、共渡、清桌胜利各获得一类钥匙碎片，三类集齐合成钥匙；跨桌保留，同类不重复授予。
- 正式失败与玩家受罚分开记录；实际贡献少者受罚，同贡献双方受罚。玩家第三次受罚失去心脏并接任荷官；NPC 单独受罚不消耗玩家器官，详见 v2 状态机设计。
- 完整试玩目标为 8—12 分钟，路演为 3 分钟；默认路演使用算计者NPC。
